# rm-gestio-node

Portafolio de Luis Ricardo Medina, desarrollador full stack.
En producción: https://rm-gestio-node.vercel.app

## Desarrollo

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Next.js 15 (App Router), TypeScript y Tailwind. Las secciones viven en `src/components/` y las capturas de proyectos en `public/proyectos/`.

El formulario de contacto guarda los mensajes en Google Sheets mediante Apps Script; la configuración está en `GOOGLE_SHEETS_SETUP.md`.
