# ⚡ INICIO RÁPIDO - 5 MINUTOS

## 1️⃣ Prueba Local (2 min)

```bash
cd my-company-landing
npm install
npm run dev
```

Abre: http://localhost:3000 ✨

## 2️⃣ Personaliza (1 min)

Edita estos archivos con TUS datos:

```
src/components/Header.tsx      → Nombre de empresa (busca "RM Dev")
src/components/About.tsx        → Sobre ti
src/components/Contact.tsx      → Tu email/teléfono
src/components/Projects.tsx     → Tus proyectos
src/components/Clients.tsx      → Tus clientes
```

## 3️⃣ Sube a GitHub (1 min)

```bash
git add .
git commit -m "Mi landing page"
git push
```

## 4️⃣ Deploy en Vercel (1 min)

1. Ve a https://vercel.com
2. Login con GitHub
3. Haz clic "New Project"
4. Selecciona tu repo
5. Haz clic "Deploy"
6. ¡LISTO! 🚀
